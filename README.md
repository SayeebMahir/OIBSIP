# Oasis Infobyte Data Science Internship (OIBSIP)

Welcome to my repository for the Oasis Infobyte Data Science Internship. This repository contains the code, datasets, and documentation for the machine learning and data analysis tasks I completed during the program.

## 📂 Repository Structure

* **[Task_1_Iris_Classification](./Task_1_Iris_Classification/)**: A machine learning classification model to identify the species of an Iris flower based on its physical measurements.
* **[Task_2_Unemployment_Analysis](./Task_2_Unemployment_Analysis/)**: An exploratory data analysis (EDA) project focusing on the impact of the COVID-19 pandemic on India's unemployment rate.
* **[Task_3_Car_Price_Prediction](./Task_3_Car_Price_Prediction/)**: A regression model built to predict the selling price of used cars based on historical vehicle data.

## 🛠️ Tech Stack

* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook / Google Colab
